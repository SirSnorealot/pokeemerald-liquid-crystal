# LC Map Registry

Maps every project map that was imported from the LC export to its source folder in `lc_maps/data/maps/`.

**How to use:**
- Before importing a map, check this table to see if it is already present.
- After importing a map, add it to the appropriate section below.
- The `lc_maps Folder` column is the folder name under `lc_maps/data/maps/` that was used as the import source.
- Maps that are still placeholder Hoenn maps (not yet imported from LC) are **not** listed here.
