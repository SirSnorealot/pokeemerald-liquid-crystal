# LC Layout Registry

Maps every project layout that was imported from the LC export to its source folder in `lc_maps/data/layouts/`.

**How to use:**
- Before importing a layout, check this table to see if it is already present. (Phase 2 of IMPORT_MAP_FROM_EXPORT uses md5 hashing for this; this table is a human-readable complement.)
- After importing a layout, add it to the appropriate section below.
- The `lc_maps Folder` column is the hex-address folder name under `lc_maps/data/layouts/` that the `.bin` files were copied from.
- Layouts that are still placeholder Hoenn layouts (not yet replaced) are **not** listed here.
