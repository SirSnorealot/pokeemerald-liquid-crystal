# LC Tileset Registry

Maps the original exported tileset name to its LC project identifier.

**AMAP #** — the tileset number assigned in AdvanceMap. This
is filled in manually by the developer; it is not derivable from the project
source alone.

When adding a new tileset entry, leave AMAP # as `?` and fill it in afterward.
